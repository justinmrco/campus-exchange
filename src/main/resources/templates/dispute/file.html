What happens when you file a dispute

  1. Transaction is paused — locked and marked DISPUTED immediately.
  2. Admin is notified — a platform admin will review the dispute and your reason.
  3. Track in My Disputes — monitor the status and see admin notes in My Disputes.

Common reasons: seller no-show, item mismatch, token verification failure, item condition different from listing.

Be specific — include location, time, and what actually happened vs. what was agreed.
